# Wine Market Intelligence Dashboard

## Overview
Professional wine sales analytics dashboard for control state market analysis.

## Usage
1. Open `index.html` in any modern web browser
2. Load wine data using `window.loadWineData(yourDataArray)`
3. Use filters to analyze different market segments

## Data Format
Expected CSV/JSON fields:
- RETAIL_SALES, WAREHOUSE_SALES, RETAIL_TRANSFERS
- YEAR, MONTH, ITEM_TYPE
- review_variety, review_country, review_price
- SUPPLIER, review_winery, ITEM CODE

## Browser Compatibility
Works in Chrome, Firefox, Safari, Edge (modern versions)

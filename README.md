## Quick Start Validation
1. Clone repo: `git clone https://github.com/ac604605/Montgomery_County_Dashboard.git`
2. Navigate to folder: `cd Montgomery_County_Dashboard`
3. Install dependencies: `pip install -r requirements.txt`
4. Open Jupyter: `jupyter notebook`
5. Open the main notebook: "Montgomery County Maryland Wine Sales Dashboard V2.ipynb"
6. Run cells in order - first cell will validate environment
